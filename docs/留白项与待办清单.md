## 二、留白项详细说明

### 2.1 QQ空间动态采集 — 需要手动扫码登录

**当前状态**：代码已就绪（`qzone_scraper.py`），但首次使用必须手动操作。

**留白原因**：腾讯要求二维码扫码登录，无法自动化。

#### 待办步骤：

- [ ] **T1: 首次登录**
  - 运行 `python scripts/qzone_scraper.py`
  - 终端显示二维码 → 用目标QQ号扫码
  - Cookie 自动保存到 `data/qzone_cookies.json`
  
- [ ] **T2: 配置监控目标QQ号**
  - 在 `config/config.json` 中添加：
  ```json
  {
    "qzone": {
      "target_qq": "目标QQ号",
      "scan_mode": true,
      "fullscan_first": true
    }
  }
  ```

- [ ] **T3: 执行首次全量扫描**
  - 登录成功后运行全量扫描
  - 预计耗时：30分钟~2小时（取决于说说数量）
  - 结果保存到 `data/qzone_shuos.json`

- [ ] **T4: 配置增量扫描定时任务**
  - 基于时间戳增量获取新说说
  - 建议频率：每2小时一次
  - Cookie过期后需重新扫码（通常几天到几周）

**风险提示**：
- Cookie 有效期不固定，过期后必须重新扫码
- 高频请求可能触发风控，已设置1~3秒随机间隔
- 建议使用非主力QQ号操作

### 2.3 QQ群消息采集 — NapCat + qq-chat-exporter 未部署

**当前状态**：代码框架已完成（`qq_group_scraper.py`），但依赖的外部服务未安装。

#### 待办步骤：

- [ ] **T9: 安装 NapCatQQ**
  - 下载地址：https://github.com/NapNeko/NapCatQQ/releases
  - 选择 Windows 桌面版
  - 解压到项目目录外（建议独立目录）
  - 启动后用QQ扫码登录
  
- [ ] **T10: 配置 NapCat HTTP API**
  - 编辑 NapCat 配置文件 `config/onebot11_你的QQ.json`
  - 确保 HTTP 服务开启，端口默认 3001
  - 更新项目 `config/config.json` 中的 NapCat 配置：
  ```json
  {
    "napcat": {
      "host": "http://localhost:3001",
      "access_token": "your_token"
    }
  }
  ```

- [ ] **T11: 部署 qq-chat-exporter（全量历史导出）**
  - 方式一：独立部署（推荐）
    ```bash
    # 从 GitHub Releases 下载最新版 v5.5.64+
    # https://github.com/shuakami/qq-chat-exporter/releases
    # 解压后运行 launcher-user.bat
    ```
  - 方式二：作为NapCat插件挂载（Docker环境）
  - 扫码登录 → 复制Token → 打开 http://localhost:40653/qce-v4-tool

- [ ] **T12: 配置目标群列表**
  - 在配置文件中添加要监控的群号：
  ```json
  {
    "qq_groups": [
      {"group_id": "群号1", "name": "群名称1"},
      {"group_id": "群号2", "name": "群名称2"}
    ]
  }
  ```

- [ ] **T13: 执行首次全量导出**
  - 通过 qq-chat-exporter Web界面 或 API 导出
  - 选择目标群 → 选择时间范围 → 导出JSON格式
  - 结果保存到 `data/qq_exports/` 目录

- [ ] **T14: 配置定时自动备份**
  - qq-chat-exporter 支持内置定时备份功能
  - 建议备份频率：每12小时一次
  - 备份格式：JSON（便于程序解析）

**风险提示**：
- ⚠️ **必须保持QQ在线**，掉线后需重新登录
- ⚠️ 高频导出可能触发腾讯风控
- ⚠️ 群消息涉及他人隐私，存储和使用须符合法律法规
- 💡 **建议使用小号操作**，不要在主力QQ上运行
