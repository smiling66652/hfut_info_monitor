| 方案 | 类型 | 免费额度 | 超出单价 | 调用限制 | 部署要求 |

| 腾讯云 OCR（通用印刷体识别） | 云端 API | 1,000 次/月 | ¥0.003/次 | QPS=2 | 需注册腾讯云，获取 SecretId/SecretKey |

| 硬件 | 预估处理速度 | 额外电费/月（24h 运行） | 说明 |
|------|:----------:|:-------------------:|------|
| CPU（i5-12400F 级别） | ~0.5-1 张/秒 | ~¥5-10 | 适合低频场景 |

| **监控成本** | 需关注调用量 | 需关注调用量 | 需关注磁盘空间 |

## 五、结论与建议

### 5.1 多级方案设计

```
┌─────────────────────────────────────────────────┐
│  Plan A（主力）: 本地 PaddleOCR                   │
│  ├─ 优点: 完全免费、无限制、离线可用               │
│  ├─ 缺点: 需要安装依赖、首次加载慢                 │
│  └─ 适用: 日常监控，绝大多数场景                    │
├─────────────────────────────────────────────────┤
│  Plan B（备选）: NapCat 下载图片 + 本地 OCR        │
│  ├─ 优点: 利用 NapCat get_image 接口直接下载       │
│  ├─ 缺点: 需要 NapCat 服务在线                     │
│  └─ 适用: QQ 群图片需要特殊鉴权时                   │
├─────────────────────────────────────────────────┤
│  Plan C（降级）: 百度/腾讯云 OCR API               │
│  ├─ 优点: 部署简单、准确率最高                      │
│  ├─ 缺点: 需联网、有费用、有调用限制                │
│  └─ 适用: 本地 OCR 不可用时的降级方案               │
├─────────────────────────────────────────────────┤
│  Plan D（兜底）: 标记 [图片] 不做 OCR               │
│  ├─ 优点: 零成本、零延迟                            │
│  ├─ 缺点: 丢失图片中的文字信息                      │
│  └─ 适用: 所有方案均不可用时的最终兜底               │
└─────────────────────────────────────────────────┘
```

### 5.2 推荐策略

1. **开发/测试环境**：优先使用 PaddleOCR（Plan A），免费且不消耗云端额度
2. **生产环境**：
   - 主路径：PaddleOCR（Plan A）处理大部分图片
   - 降级路径：PaddleOCR 失败 → 云端 API（Plan C）作为补充
   - 兜底：均失败时标记 `[图片]`（Plan D）保留记录
3. **成本控制**：
   - 开发期可完全依赖 PaddleOCR，零成本
   - 如需使用云端 API，建议绑定费用告警避免超额
   - 腾讯云单价更低，优先选用（¥0.003/次 vs ¥0.004/次）
