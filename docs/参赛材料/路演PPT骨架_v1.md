### P1 · 封面
- **标题**：HFUT Info Monitor —— 高校智能情报中台：把散落的校园信息，按时推到你手里
- **要点**：项目名 / 一句话定位 / 团队与学院 / 参赛赛道
- **配图**：每日情报邮件截图（HTML 模板）做背景，或系统架构简图
- **讲稿提示**：10 秒开场——"我们做过一个调研：合工大的关键信息散在 5 个以上互不打通的渠道。这个系统已经替 35 位同学盯了 24 天。"

### P2 · 痛点
- **标题**：重要的通知，总是过期后才知道
- **要点**：① 5+ 渠道互不打通（官网/公众号/QQ群/QQ空间）；② 信息过载，有效通知被淹没；③ DDL 顺延、附件替换、名单更正完全不可见；④ 保研机构把"DDL 提醒"卖进 ¥199/年会员——痛点已被付费验证
- **配图**：左边 5 个渠道图标 + 右边"错过"时间线；引用保研岛收费截图
- **讲稿提示**：用真实例子讲（某竞赛报名截止顺延无人知晓），别念列表。

### P3 · 解决方案
- **标题**：抓得全 → 筛得准 → 推得到
- **要点**：四渠道采集（官网 37 栏目+公众号+QQ 空间+QQ 群）；P0/P1/P2 三级关键词 + 本地 LLM 二次判断 + OCR 兜底；HTML 邮件日报 + DDL 倒计时
- **配图**：三段式流程图（采集层→处理层→推送层），README 中的 mermaid 图可直接美化
- **讲稿提示**：只讲三步，每步一句话；技术细节留给评委问。

### P4 · 真实运行数据（本 PPT 最硬的一页）
- **标题**：不是 Demo，是跑了 24 期的真实系统
- **要点**：24 期每日情报邮件 / 35 位真实收件人 / 37 栏目 10 秒级巡检 / 257 条归档（2016-12~2026-06）/ 1,116 条全量索引 / 31,310 行自研代码（74 个文件） / 零 API 成本
- **配图**：`python scripts/stats_report.py` 终端输出截图 + 邮件发送记录列表截图（截图用 `运行证据/stats_report_实测输出_2026-10-12.txt`，与本页数字逐字一致）
- **讲稿提示**：逐个数字讲来源（"这个数字由脚本从归档 JSON 直接统计，现在就能跑给你们看"）。可现场跑一次 `python hfut.py status` 作为演示。若被问"代码量构成"，答：`scripts/` 采集 41 个 + `hfut_site/` 巡检 7 个 + 测试 3 + 助手 5 + 文档工具 3 + 入口 3 + 临时 12（明细见《代码构成明细.md》，剔除临时脚本后的保守下界 29,787 行）。

### P5 · 技术架构与可靠性
- **标题**：为"不出事故"设计的工程
- **要点**：五级采集降级链（Plan A→E）；三级存储降级（IMA→本地 JSON→Notion）；容错模块（超时 30s/冷却 2s/重试 1 次）；SPA 空壳识别 + 通用解析器（抗站点改版）
- **配图**：降级链流程图（一环失败→自动切换示意）；fault_tolerance.py 代码节选
- **讲稿提示**：强调"容错是内置的，不是事后补丁"；举 QQ 空间最易失效、五条路径兜底的例子。

### P6 · 技术壁垒
- **标题**：通用监控工具做不到的四层垂直能力
- **要点**：① 高校源库（37 栏目逐个调通，选校即用）；② QQ 群/空间/公众号采集（竞品空白）；③ 教育语义（七类分级 + A 类竞赛结构化库）；④ 零 API 成本（本地 Ollama）
- **配图**：对标矩阵表——本系统 vs changedetection.io vs 咕咕监控 vs 网页侦探（四行打勾）
- **讲稿提示**：先承认竞品存在（评委可能知道 changedetection.io），再讲"它们是通用引擎，我们是高校垂直层"，这个姿态得分。

### P7 · 差异化创新点
- **标题**：一句话别人说不出来的话
- **要点**："这条通知 3 天前被修改过，截止日期从 15 号改成了 12 号"——内容级变更检测 + 教育语义；配合：语义级去重、DDL 结构化抽取、个性化订阅（35 人从同一封邮件 → 按兴趣标签分发）
- **配图**：通知变更前后 diff 对比示意（可做 mockup）
- **讲稿提示**：这是"创新性"评分项的主打页，讲清"为什么通用工具判断不了'截止日期改了'意味着什么"。

### P8 · 商业模式与市场验证
- **标题**：赛道有付费验证，机会在垂直层
- **要点**：定价锚点 ¥99–199/年（咕咕监控 ¥198、保研岛 ¥199 已验证）；四条切口：竞赛雷达（无人做）→ 保研雷达（付费最强）→ 单校管家（10–30 所）→ B 端（真实中标预算 ¥2.4 万–12.75 万/年）
- **配图**：细分市场四象限图 + B 端中标金额条形图（数据源自 docs/招标采购调研）
- **讲稿提示**：先讲"我们调研了 20+ 国内、15+ 海外竞品"体现严肃性；B 端数字是真实中标公告，可答辩引用。

### P9 · 社会价值
- **标题**：消除信息差，机会平等
- **要点**：让不会折腾技术的普通学生也能平等获取保研/竞赛/就业信息；合规采集（只推标题+链接+摘要、尊重 robots、严格限频）；数据资产可反哺学校（历届通知 1,116 条可检索）
- **配图**：用户画像场景图（大二学生收日报选竞赛）
- **讲稿提示**：简短真诚，30 秒带过，落点在"信息差是校园里最隐蔽的不公平"。

### P10 · 团队与规划
- **标题**：超级个体 + 清晰的下一步
- **要点**：汪义航（机械工程 2024 级）· 31,310 行自研（74 个文件）· 8+ Agent 工程化方法论；三阶段路线图：赛前（内容指纹/语义去重/个性化订阅）→ 中期（变更检测/多通道推送）→ 远期（RSS·API/多校泛化）
- **配图**：路线图时间轴（与深度调研总报告第五章一致）
- **讲稿提示**：强调"规划不是拍脑袋，出自一份逐文件代码审计报告"，展示自我认知。

### P11 · 结尾
- **标题**：已经在跑的系统，等一个放大它的机会
- **要点**：一句话复述核心主张 + 24 期 / 35 人 / 37 栏目 / 0 成本 四个数字收尾 + 致谢
- **配图**：最新一期日报邮件截图 + GitHub 仓库二维码
- **讲稿提示**：以演示邀请收尾——"各位评委现在扫码，可以看到全部源码和每一条运行数据。"
