## 一、核心主张（一句话）

**"把散落在官网、公众号、QQ 群、QQ 空间的校园信息，抓下来、筛干净、按时推给你——已真实运行、零 API 成本、可验证。"**

定位升维：不是"爬虫脚本"，而是**面向高校学生的智能情报中台 / 信息差消除平台**，护城河是竞品没有的"中国高校源库 + 教育语义"垂直层。

---

## 二、痛点（问题真实、普遍、有付费验证）

1. **信息散落 5+ 个互不打通的渠道**：本部官网、宣城校区官网、微信公众号、QQ 空间、各类 QQ 群。靠人肉刷，重要竞赛报名和保研通知经常**过期后才知道**。
2. **信息过载**：QQ 群/空间日均刷屏，有效信息被表情包和广告淹没（源自作者真实使用记录的痛点图谱）。
3. **DDL 是最痛的点**：截止日期顺延、附件悄悄替换、名单更正，学生完全不可见。
4. **付费意愿已被验证**：保研机构（保研岛/后保研）把"DDL 提醒"写进收费服务清单，会员卖到 ¥199/年——说明"别错过关键时间点"是学生愿意掏钱的需求，只是被机构打包在资料里卖。

---

## 三、解决方案（三步：抓得全 → 筛得准 → 推得到）

| 环节 | 做法 | 关键设计 |
|---|---|---|
| **抓得全** | 官网 37 栏目 + 公众号 + QQ 空间 + QQ 群四渠道采集 | 静态页 requests、动态页 Playwright；QQ 空间 **Plan A→B→C→D→E 五级降级链** |
| **筛得准** | P0/P1/P2 三级关键词 + 规则引擎 + 本地 LLM 二次判断 | 竞赛/二手/有用信息三类增强检测；图片型公告 OCR 兜底 |
| **推得到** | HTML 邮件 + 每日 20:00 摘要 + DDL 倒计时 | 紧急即推、普通汇总；每日情报含"还有 N 天"倒计时 |

**差异化洞察**（下一步产品化的核心卖点）：系统不只是"有没有新通知"，还将做"已发布通知是否被悄悄改过"的内容级变更检测——*"这条通知 3 天前被修改过，截止日期从 15 号改成了 12 号"*，这句话通用监控工具说不出来，因为它们没有高校语义层。

## 五、技术壁垒（为什么别人做不了/做不好）

1. **高校源库壁垒**：高校官网有 18–30 个栏目、多套 CMS 并存、域名频繁变更。37 栏目的地址、解析器、降级策略是逐个踩坑调出来的，通用监控工具要求用户自己贴 URL，我们**选校即用**。
2. **采集渠道壁垒**：QQ 群（NapCat OneBot11）、QQ 空间（五级降级）、公众号采集——高校信息恰恰大量散落在这三处，竞品完全没有。
3. **教育语义壁垒**：保研/竞赛/教务/奖学金/基金/学术/就业七类分级 + A 类竞赛结构化库 + DDL 倒计时，是领域知识不是通用算法。
4. **少见的工程能力**：图片型公告 OCR 兜底、SPA 空壳识别、通用解析器（按详情页 URL 形态提取，抗站点改版）、发信账号自动降级与防误发闸门。
5. **成本壁垒**：规则引擎为主 + 本地 LLM 为辅，日常运行零 API 成本，同类 SaaS 每月都要烧模型费。

对标结论（源自调研）：通用网页监控赛道已有 changedetection.io（33k★免费开源）、网页侦探、咕咕监控（¥198/年）三层覆盖，正面打没有胜算；但**没有一家做"中国高校源库 + 教育语义理解"**——这正是本项目的垂直层，也是 changedetection.io 做不到的。

## 六、商业与社会价值

**市场验证**：
- 已验证赛道有付费用户：咕咕监控 Pro 年费 ¥198；保研岛会员 ¥199/年且含 DDL 提醒服务。
- 大学生工具客单价现实天花板 ¥100–300/年；建议定价 **¥9.9–29/月 或 ¥99–199/年**，用"保研季/竞赛报名/选课"等关键节点触发付费。

**四条细分切口**（按可行性排序）：
1. **竞赛报名雷达**：几乎无人做，竞争低，与我们已有 A 类竞赛库直接衔接。
2. **保研/考研信息雷达**：付费意愿最高（保研机构同类服务卖到数千元）。
3. **单校深度管家**：从合工大起步复制到 10–30 所目标校（源库是人力活，控节奏）。
4. **B 端：学院/学工部门**：已核实的 2026 年真实高校"舆情+网站巡检"中标预算 ¥2.4 万–12.75 万/年（德州学院 ¥127,500、西南科技大学 ¥86,600/年等），能力范围与本项目高度重合，客单价远高于 C 端。

**社会价值**：消除高校信息差，让普通学生（不会配 Docker、不想折腾的人）也能平等获取保研/竞赛/就业机会；信息只推标题+链接+摘要，尊重 robots 与站点协议，合规采集。
