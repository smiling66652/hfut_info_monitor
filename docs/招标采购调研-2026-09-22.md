## 四、接口线索（供爬虫修复 / 后续自动化参考）

官网为 Nuxt SPA + 云采通（yuncaitong.cn）供应商门户，关键接口如下：

### 4.1 公告列表查询接口（官网 CMS）
- **地址**：`https://zb.hfut.edu.cn/sfw_cms_new/e?page=cms.psms.publish.query&window_=json`
- **方法**：POST（Content-Type: application/json）
- **请求体字段**（JSON）：
  - `type`：公告类型数组
    - 采购公告类：`["CSXQ","BYXQ","YQXQ","ZCXQ","ZJGG"]`
    - 结果公告类：`["ZCGS","ZCGG","BGGG","FBGG"]`（其中 `ZCGG`=中标/成交公告）
  - `keywords`：关键词模糊搜索（如 `"月饼"`），可空
  - `shopType` / `catalog` / `isEnd` / `notShopType`：筛选条件，可置 `null`/`[]`
  - `limit`：每页条数（字符串，如 `"50"`）
  - `start`：起始页（字符串，如 `"1"`）
- **返回**：`{ count, resultset:[{id, subject, beginTime, tenderNo, tenderName, type, fullUrl, agentName, ...}], ... }`
- 注：列表里的 `fullUrl` 指向云采通供应商门户（`https://zb.hfut.edu.cn/provider/#/publish/{syncId}`）。

### 4.2 公告详情接口（云采通门户）
- **详情元数据**：`https://provider.yuncaitong.cn/api/publish/{syncId}?`
  - 返回 JSON，含 `subject, projectCode, projectName, type, contentType, agent, attach` 等；正文 `content` 字段为空时表示正文以 PDF 形式发布。
- **正文 PDF**：`https://provider.yuncaitong.cn/publish/{YYYY}/{MM}/{DD}/{syncId}/content.pdf?zoom=0.9`
  - 中标企业、单价、联系方式等关键字段在 PDF 正文中。
- **访客计数（无关）**：`https://provider.yuncaitong.cn/api/publish/{syncId}/visit`

### 4.3 其他观察到的接口（页面加载时调用）
- 门户鉴权：`https://app.yuncaitong.cn/api/auth?`、`https://api.yuncaitong.cn/time?`
- 栏目导航：`https://zb.hfut.edu.cn/sfw_cms_new/e?page=cms.portalCategory.listCategory&window_=json`

> 爬虫修复建议：直接 POST 4.1 接口并按 `keywords` 过滤即可拿到全部年份的月饼类公告（本次以关键词"月饼"共检索到 7 条历史记录：2026/2025/2024/2023/2022/2021/2017）；详情需再请求 4.2 的 `content.pdf` 并做 PDF 文本提取（正文多为 PDF 而非 HTML）。
